# The Intelligence Coalition organization profile

This repository manages the public GitHub organization profile for [The Intelligence Coalition](https://intelligencecoalition.com). Its GitHub repository name is `theintelligencecoalition/.github`.

- [profile/README.md](profile/README.md) is the organization Overview content.
- [profile/assets/coalition-logo.png](profile/assets/coalition-logo.png) is the existing Coalition logo, copied unchanged from the website's `public/images/brand/logo.png`.

The repository root contains `profile/` directly. Do not add a nested `.github/` directory. The website is maintained separately.

## Maintenance

Use GitHub Flavored Markdown and relative asset paths. Keep organization, workforce, and technology perspectives balanced. Link only to published resources, and verify destinations when updating them. GitHub controls typography and page colors; the transparent logo and simple document layout support light and dark themes and narrow screens.

## Publishing

Publish only after explicit approval. Create or use the public `theintelligencecoalition/.github` repository and push these files to its default branch. Then inspect the organization's Overview in its public view, including the logo, links, light and dark themes, and a mobile viewport. GitHub documents this structure in [Customizing your organization's profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
